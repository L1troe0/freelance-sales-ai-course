# AIW Telegram-бот

Бот для канала AIW: делает две вещи.

1. **Автопостинг** — раз в день публикует в канал очередной пост из `posts.json` (по кругу).
2. **Выдача курса** — по команде `/start` в личке присылает пользователю кнопку со ссылкой на курс.

## Шаг 1. Создать бота

1. Открыть **@BotFather** в Telegram → `/newbot`
2. Указать имя и username (например `AIW_saityii_bot`)
3. BotFather выдаст **токен** — длинную строку вида `123456789:AA...`.
   **Никому не показывайте этот токен и не вставляйте его в чат с кем-либо, включая сюда** — это полный доступ к боту.

## Шаг 2. Добавить бота в канал

1. Зайти в свой канал → **Управление каналом → Администраторы → Добавить администратора**
2. Найти своего бота по username, добавить
3. Обязательно включить право **«Публикация сообщений»**

## Шаг 3. Настроить переменные окружения

Бот читает 4 переменные:

| Переменная | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHANNEL_ID` | username канала вида `@aiw_channel`, либо числовой id (можно узнать через @userinfobot, переслав ему пост из канала) |
| `COURSE_URL` | (необязательно) ссылка на курс, по умолчанию уже стоит ваша GitHub Pages ссылка |
| `AUTOPOST_HOUR` | (необязательно) час дня для автопостинга, по умолчанию 12 |

## Шаг 4. Запустить

Локально (для проверки):

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="ваш_токен"
export TELEGRAM_CHANNEL_ID="@aiw_channel"
python bot.py
```

Бот должен работать **постоянно** (24/7), иначе не сможет ни принимать `/start`, ни постить по расписанию. Локальный компьютер для этого не годится — нужен сервер. Проще всего:

- **Railway.app** или **Render.com** — бесплатный тариф, деплой из этой папки за 5 минут (Start Command: `python bot.py`, переменные окружения задаются в настройках проекта — токен туда, никогда в код и не в чат)
- Свой VPS + `systemd`/`tmux`, если уже есть сервер

## Как добавить свои посты

Отредактируйте `posts.json` — это просто список текстов (можно с `<b>жирным</b>`, Telegram HTML-разметка). Бот публикует их по кругу, один в день, и запоминает, на каком остановился, в `state.json`.
